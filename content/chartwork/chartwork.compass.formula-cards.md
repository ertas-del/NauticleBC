# Compass errors: the formula cards

This lesson is built to be easy to read.

- Short lines.
- One idea at a time.
- Every card has a worked example.

Read each card out loud. Do one card at a time.

---

## Card 0: The five words

Say them in order. Use the first letters: **T V M D C**.

```
T  True        (real north, from the chart)
V  Variation   (the error in the earth)
M  Magnetic    (where magnetic north is)
D  Deviation   (the error in your boat)
C  Compass     (what your compass shows)
```

Memory hook:

> **T**ake **V**ery **M**ild **D**rinks **C**arefully.

Two rules are all you need.

- **Going down** (True to Compass): ==East is least. West is best.==
  East is **subtracted**. West is **added**.
- **Going up** (Compass to True): do the **opposite**.
  ==Compass Add East== gives True. This is **CADET**.

---

## Card 1: Where do the numbers come from?

- **Variation** comes from the **compass rose** on the chart.
- **Deviation** comes from your **deviation card**.

Both have a direction: **East (E)** or **West (W)**.

---

## Card 2: True to Compass (going down)

**Steps**

1. Write the true course.
2. Apply **variation**. East −, West +. This gives **Magnetic**.
3. Apply **deviation**. East −, West +. This gives **Compass**.

**Example**

- True course: 090°
- Variation: 17° East
- Deviation: 2° West

```
True              090°
Variation 17°E    −17°     (East is least: subtract)
Magnetic          073°
Deviation 2°W     +2°      (West is best: add)
Compass           075°
```

Answer: ==Steer 075° by compass.==

---

## Card 3: Compass to True (going up)

Do the opposite. East is **added**. West is **subtracted**.

**Example**

- Compass bearing: 075°
- Deviation: 2° West
- Variation: 17° East

```
Compass           075°
Deviation 2°W     −2°      (West: subtract going up)
Magnetic          073°
Variation 17°E    +17°     (East: add going up)
True              090°
```

Answer: ==True bearing is 090°.==

---

## Card 4: Going past 360 or below 0

A compass has 360 degrees. Numbers wrap round.

- If the answer is **360 or more**: **subtract 360**.
- If the answer is **below 0**: **add 360**.

**Example**

- Compass bearing: 350°
- Deviation: 3° East
- Variation: 17° East

```
Compass           350°
Deviation 3°E     +3°
Magnetic          353°
Variation 17°E    +17°
True              370°  → too big, subtract 360
True              010°
```

Answer: ==True bearing is 010°.==

---

## Card 5: A small number going down

**Example**

- True course: 270°
- Variation: 17° East
- Deviation: 4° East

```
True              270°
Variation 17°E    −17°
Magnetic          253°
Deviation 4°E     −4°
Compass           249°
```

Answer: ==Steer 249° by compass.==

---

## Card 6: Compass error and deviation from a bearing

You take a compass bearing of a mark. You also know its **true** bearing from the chart.

**Formula**

> Compass error = True − Compass

- If the answer is **positive**, the error is **East**.
- If the answer is **negative**, the error is **West**.

**Example**

- Compass bearing of a light: 062°
- True bearing from the chart: 071°

```
Compass error = 071 − 062 = +9°  → 9° East
```

Then find deviation.

> Compass error = Variation + Deviation  (East +, West −)

If variation is 16° East:

```
9 = 16 + Deviation
Deviation = 9 − 16 = −7°  → 7° West
```

Answer: ==Deviation is 7° West on that heading.==

---

## Card 7: Variation changes over the years

The compass rose shows the variation for a certain year, and how it changes each year.

**Example**

- Rose says: 17° 00′ East (2010), decreasing 0° 10′ each year.
- You need the variation for 2020.

```
Years passed: 10
Change: 10 × 10′ = 100′ = 1° 40′ (decrease)
Variation 2020 = 17° 00′ − 1° 40′ = 15° 20′ East
```

Answer: ==Variation is about 15° 20′ East.==

---

## Card 8: Check the compass

1. Find two marks in line (a **transit**). Read the true bearing from the chart.
2. Steer so the marks are in line. Read the compass heading.
3. Work out the compass error (Card 6).
4. Write the deviation on your **deviation card** for that heading.
5. Repeat on other headings.

---

## Common mistakes

- Adding East when going down. (East is least.)
- Forgetting to wrap round at 360.
- Using an old variation.
- Putting a phone next to the compass.

## Check yourself

1. True 180°, variation 16° East, deviation 0°. What is the compass course?
2. Compass 010°, deviation 2° West, variation 16° East. What is the true bearing?
3. What do the letters TVMDC stand for?
4. What does CADET mean?
